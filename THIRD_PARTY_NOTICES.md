# Third-Party Notices And Provenance

The adapter source retains its existing MIT license and the copyright notice
in [LICENSE](LICENSE). The clean distribution is prepared from selected source
files in a new Git history, not from the previous workspace history. The release
package is checked separately for excluded configuration, captures, and
development artifacts.

## Dependencies

The runtime dependency `@iobroker/adapter-core` is an ioBroker project licensed
under MIT. Dependencies are installed separately by npm and retain their own
licenses and notices. Development tools are not shipped inside the adapter's
runtime package. Refer to each dependency's package for its applicable license.

## Protocol And Parameter Information

Protocol descriptions and parameter mappings document interoperability with the
W600/MyHeatPump communication observed during prior development. They are not
manufacturer source code, a manufacturer approval, or a promise of compatibility
with every controller or firmware. Original cloud pages, application binaries,
manual PDFs, and private communication captures are excluded from the selected
source files and runtime package.

Some short parameter option labels originate from the manufacturer's settings
form. Only minimal interoperability metadata is retained. Applicable source
terms and permissions for those labels have not been independently reviewed;
the adapter's MIT license does not establish rights in third-party material.

HEIKO, SPRSUN, Neoheat, USR, and MyHeatPump identify relevant products or services;
ioBroker identifies the platform/project. Relevant names and marks remain with
their respective holders. This adapter is independent and does not claim
endorsement by those organizations.

The adapter icon was supplied by the project owner as AI-generated artwork for
